# 文档索引与基线说明

## 1. 协议基线（最高优先）

- `智能巡查系统自组网协议-003.pdf`：协议原始约束来源。
- `LM软件设计文档.md`：当前软件协议基线（字段、状态机、接口约束）。

## 2. 工程实现文档（当前有效）

- `设计文档（初稿）.md`：工程侧实现基线与分层落地约束。
- `任务分解技术书.md`：任务拆解、完成度、阶段里程碑与增量记录。
- `协议状态转移深度拆解.md`：网关/节点状态转移细化与实现对照。
- `协议审查报告.md`：实现与协议的一致性审查结论。
- `验证与回归清单.md`：板测与仿真验证记录、回归口径。
- `四板双串口联调执行表.md`：多板联调操作模板与执行结果。
- `协议库软件实现讲解.md`：面向开发者的实现解读文档。

## 3. 库内文档入口

- `../lib/Ad-Hoc-lib/docs/README.md`：协议库移植、配置、使用、实现说明总览。
- `../lib/Ad-Hoc-lib/test/README.md`：Windows 仿真入口与场景说明。

## 4. 归档策略

- 已不作为当前主线基线、仅保留历史决策依据的文档，统一放入 `docs/archive/`。
- 归档文件不删除，仅标注“适用阶段”与“替代关系”，避免与当前基线混淆。
