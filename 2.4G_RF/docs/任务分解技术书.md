# 自组网协议任务分解技术书（v0.1）

## 1. 文档目的

本文档将 [设计文档（初稿）](D:/Desktop/ch32/0.ch32v208_dome/2.4G_RF/docs/设计文档（初稿）.md) 的“编码前核对清单”转化为可执行任务，作为实施与验收依据。
协议约束始终以 `docs/智能巡查系统自组网协议-003.pdf` 为最高优先级；本轮时间戳修订以 `docs/软件设计文档.md` 为派生约束来源，且不直接修改该文件。

## 2. 执行边界

- 新协议代码仅落在 `lib/Ad-Hoc-lib/` 及其适配目录。
- 不在 `lib/AROS-RF-LIB/` 中实现新协议逻辑。
- 采用链路层/协议层解耦架构，旧任务保留但不删除。
- `CRC8` 参数固定为：`poly=0x07, init=0x00, xorout=0x00, refin=false, refout=false`。
- `Ad-Hoc-lib API v0.1` 保留为历史基线；当前实现接口基线为 `v0.2`。
- 最新协议要求时间戳位于 `Content/M` 内：`A` 帧 `LMT_A(4B)`、`D` 帧 `LMT_D(3B)`，不再采用独立帧级 `Timestamp(2B)`。

## 4. 任务详情

### T00 工程骨架与构建接入

- 目标：创建 `Ad-Hoc-lib` 目录与最小编译单元，保证不影响现有功能默认路径。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/`
  - `lib/Ad-Hoc-lib/src/`
  - `lib/Ad-Hoc-lib/port/ch32v208/`
  - `xmake.lua`
- 产出：
  - 冻结 `v0.1` API 头文件与空实现。
  - 新链路构建入口接入并作为默认主路径。
- 验收标准：
  - 默认构建包含 `Ad-Hoc-lib`，且可稳定编译。
  - 旧任务代码保留但不作为新协议主路径入口。
- 依赖：无（首任务）。

### T01 协议帧模型与编解码

- 目标：实现 32B 协议帧结构、字段编码和解码。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_frame.h`
  - `lib/Ad-Hoc-lib/src/adhoc_frame.c`
- 产出：
  - A/D 帧第1字节位定义处理。
  - `S` 字段（11bit域+29bitID）编解码。
  - `M` 字段 ID 标志（高3位）处理。
- 验收标准：
  - 编码后固定 32B。
  - 解码后字段回读一致。
- 依赖：T00。

### T02 CRC8与帧校验链路

- 目标：实现固定参数 CRC8 与收发校验流程。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_crc8.h`
  - `lib/Ad-Hoc-lib/src/adhoc_crc8.c`
  - `lib/Ad-Hoc-lib/src/adhoc_frame.c`
- 产出：
  - CRC8 计算与附加/校验接口。
  - 校验失败帧丢弃路径。
- 验收标准：
  - 覆盖范围严格为 `第1字节+V+S+M`。
  - 错误 CRC 帧被识别拒绝。
- 依赖：T01。

### T03 时隙与时序基座

- 目标：实现 `T1/T2/T3/T4` 驱动基座与派生量计算。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_timing.h`
  - `lib/Ad-Hoc-lib/src/adhoc_timing.c`
- 产出：
  - `T5=T1+T2`，`T6=T3+T4`，`n=T5/T1`，`m=T6/T3` 计算与校验。
  - 奇偶时隙约束判定函数。
- 验收标准：
  - 参数关系可被程序化断言。
  - 奇偶约束与 `V` 联动正确。
- 依赖：T00。

### T04 组网状态机（信标优先）

- 目标：实现 `ST1/U1/UN/C1/CN` 主状态机，优先打通信标链路。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_sm.h`
  - `lib/Ad-Hoc-lib/src/adhoc_sm.c`
- 产出：
  - 弱/中/强信号入网判定。
  - 30 周期重试与超时回退 ST1。
  - 网关 `A V=0` 周期发射与 `T2` 收集窗口。
- 验收标准：
  - 信号条件和重试行为与 `003.pdf` 一致。
- 依赖：T01、T02、T03。

### T05 组网应答与列表管理

- 目标：实现上级确认列表与 5 条应答打包。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_reply_list.h`
  - `lib/Ad-Hoc-lib/src/adhoc_reply_list.c`
  - `lib/Ad-Hoc-lib/src/adhoc_sm.c`
- 产出：
  - 组网应答列表管理（FIFO、补0）。
  - ID 标志 `0..7` 语义对应分支。
- 验收标准：
  - 单帧组网应答最多 5 条，不足补 0。
  - 上级确认下级入网时使用 `flag=7 + 子节点ID`，不再用请求绑定编号 `0..5` 作为确认命中位。
- 依赖：T04。

### T06 数据面传输与去重

- 目标：实现 D 帧路径、`ID+LMT_D` 去重和网关 3 条应答，并补齐 `source_id_flag` 语义。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_data_plane.h`
  - `lib/Ad-Hoc-lib/src/adhoc_data_plane.c`
- 产出：
  - 原发/转发判定。
  - 去重缓存（默认 6h 窗口）。
  - 网关应答打包（最多 3 条 `ID+LMT_D`）。
  - 原发/转发场景下 `source_id_flag` 约束落地。
- 验收标准：
  - 重复数据可识别合并。
  - 3 条上限正确执行。
  - `source_id_flag` 与设计文档第 `4.7.3` 节一致。
- 依赖：T01、T02、T03、T05。

### T07 多网关取舍与重组网

- 目标：实现方向锁定策略与重组网回退。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/src/adhoc_sm.c`
  - `lib/Ad-Hoc-lib/include/adhoc_sm.h`
- 产出：
  - 网关组网时间窗控制（如 30s）：窗口结束后停止 `A V=0` 组网发射并进入等待/锁定态。
  - 多网关邻居表维护：先落轻量 `Top-K Cache`（当前 `K=6`），缓存候选上级（网关号/级别/RSSI/最近命中周期）并执行优选。
  - 优先“强信号+低级别”选择。
  - 锁定后仅响应所选方向。
  - 重组网到期回退 ST1（先提供本地计时接口，后续再补全全网统一结束时刻对齐）。
  - 将 `LMT_A(4B)` 作为 `A` 帧 `Content` 内时间字段接入组网窗口推导；上一轮“显式 Epoch 传播不可落地”的结论不再作为主线约束。
- 验收标准：
  - 组网时间窗到期后，网关不再持续周期发射 0 级组网消息。
  - 邻居表优选行为与文档规则一致，不再依赖单一 `candidate` 覆盖更新。
  - 锁定/释放条件符合设计文档第 11 节。
- 依赖：T04、T05。

### T08 链路适配层（AROS-RF）

- 依赖：T00、T01、T02。

### T11 时间戳模型迁移（已完成）

- 目标：将软件从上一轮“帧级 `Timestamp(2B)+Content(22B)`”迁移到“`Content` 内 `LMT_A/LMT_D`”模型，并完成接口基线切换。
- 主要修改位置：
  - `lib/Ad-Hoc-lib/include/adhoc_frame.h`
  - `lib/Ad-Hoc-lib/src/adhoc_frame.c`
  - `lib/Ad-Hoc-lib/include/adhoc_reply_list.h`
  - `lib/Ad-Hoc-lib/src/adhoc_reply_list.c`
  - `lib/Ad-Hoc-lib/include/adhoc_data_plane.h`
  - `lib/Ad-Hoc-lib/src/adhoc_data_plane.c`
  - `lib/Ad-Hoc-lib/include/adhoc_api.h`
  - `app/tasks/ad_hoc_task.c`
- 产出（已完成）：
  - 恢复帧壳为 `Header(1B)+Level(1B)+Sender(5B)+Content(24B)+CRC8(1B)`。
  - `A` 帧 `Content[0..3]` 写入/解析 `LMT_A`，确认列表最多 `5` 条。
  - `D` 数据帧 `Content[0..2]` 写入/解析 `LMT_D`，用户载荷调整为 `17B`。
  - `D` ACK 使用 `ID(4B)+LMT_D(3B)`，单帧最多 `3` 条。
  - `Ad-Hoc-lib API` 升级到 `v0.2`，避免继续暴露旧 `seq_no/user[16]` 语义。
- 验收标准（当前状态）：
  - 编解码后仍固定 `32B`，CRC8 覆盖 `Header+Level+Sender+Content`。
  - `LMT_A` 已用于组网窗口相关计算，且不再依赖独立帧级 timestamp。
  - `source.node_id + LMT_D` 已用于去重、ACK 命中与 TX report 回传。
- 依赖：T01、T05、T06、T07、T09。
